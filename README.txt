Paws & Homes — pup adoption center website
============================================

Open index.html in a browser to preview the site.

Included:
- Responsive landing page
- Adoptable pup cards
- Filter buttons
- Adoption process section
- Responsive mobile layout
- Working demo application modal/form
- No external dependencies; everything is contained in index.html

Before publishing, replace the demo pup artwork/content, contact email, statistics,
and form handler with your real adoption-center information.
